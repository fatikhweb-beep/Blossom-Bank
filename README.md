# Blossom Bank — GitHub Pages / PWA

این پوشه را در ریشه یک مخزن GitHub قرار بده و از مسیر Settings → Pages انتشار را فعال کن. سپس آدرس HTTPS سایت را با Chrome باز کن و Install app را بزن.

- نام برنامه: Blossom Bank
- آیکون: تصویر ارسالی کاربر، بدون حاشیه سفید و با گوشه‌های گرد
- منوی پایین موبایل: پس‌زمینه کاملاً سفید
- صفحه شروع نصب‌شونده: پس‌زمینه صورتی پاستیلی
- Service Worker برای کش آفلاین و دریافت رویداد Push آماده است.

## اعلان‌ها
برای اعلان محلی، مجوز اعلان را از داخل برنامه فعال کن. برای دریافت Push در زمانی که برنامه بسته است، یک سرویس سمت سرور باید Push Subscription را دریافت کند و پیام را با Web Push ارسال کند؛ وجود Service Worker به‌تنهایی ارسال زمان‌بندی‌شده را فعال نمی‌کند.

## نکته داده‌ها
اطلاعات برنامه در حافظه محلی همان مرورگر/دستگاه ذخیره می‌شود و خودکار بین نسخه مرورگر و نصب‌شده همگام نمی‌شود. پیش از جابه‌جایی نسخه، از اطلاعات مهم پشتیبان بگیر.
